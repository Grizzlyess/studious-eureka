# Desafio Vaga Júnior - To-Do List

## Descrição
Esta é uma aplicação web que consiste em um sistema de gerenciamento de tarefas, onde os usuários podem criar, visualizar, editar e excluir tarefas. O projeto foi desenvolvido utilizando **Java** e o framework **Spring Boot**.

## Funcionalidades do Software
O sistema conta com um **CRUD** completo de tarefas:
* **Criar:** Permite o cadastro de novas tarefas.
* **Visualizar:** Exibe a lista de tarefas cadastradas.
* **Editar:** Permite alterar os dados de uma tarefa existente.
* **Excluir:** Remove uma tarefa do sistema.

## Requisitos Atendidos
* **Banco de Dados:** Utilizado o banco de dados em memória **H2 Database** para facilitar a execução e testes da aplicação.
* **Campos da Entidade de Tarefa:**
  * Nome
  * Descrição
  * Realizado
  * Prioridade
